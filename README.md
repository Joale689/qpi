## Hinweis

Der Unterstützungsbereich ist vorbereitet, aber der Zahlungslink ist noch deaktiviert.
Im JavaScript steht dafür:

const DONATION_URL = "";

Erst nach steuerlicher Klärung und Auswahl eines Zahlungsanbieters sollte dort ein echter externer Unterstützungslink eingetragen werden.
